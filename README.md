# ⚔️ 單字冒險 Word Quest — 兒童英語學習 RPG

依照 [English_Learning_RPG_GDD.md](English_Learning_RPG_GDD.md) 企劃書實作的網頁版單字學習 RPG。
答對英文單字題目就能攻擊怪獸，答錯則被反擊 — 把背單字變成打怪、升級、進化、收服的冒險！

## 🚀 如何開始遊戲

**方法一（推薦）：本機伺服器**
```
cd D:\work\Claude\project\07_RPG_word\work
python serve.py
```
然後用瀏覽器開啟 http://localhost:8123 （serve.py 停用快取，改完程式重新整理就生效）

**方法二：直接開啟**
直接用瀏覽器（Chrome / Edge）打開 `index.html` 也可以玩。

## 🧊 3D 版本
另有 **3D 立體世界版**位於 [3d/index.html](3d/index.html)（伺服器模式網址：http://localhost:8123/3d/ ）：
- 使用 Three.js（已內附於 `3d/lib/`，離線可玩）
- **身歷其境第三人稱視角**：鏡頭在玩家身後平滑跟隨，有地平線、霧氣景深、光影、水波與營火光源；**鏡頭固定朝向不旋轉**（防暈設計），方向鍵與小地圖方位一致
- **戴帽小冒險者主角**：程式繪製的 Q 版全身角色（探險帽、綠上衣、背包、靴子），會隨移動方向翻面、走路彈跳；2D 版地圖同步使用
- 戰鬥採 GDD 的斜對角視角 3D 舞台（我方左下、敵方右上），衝鋒/受擊/倒下都有 3D 動畫
- **與 2D 版共用同一份遊戲邏輯與存檔**——兩個版本可以互相接續進度，數值調整（GAME_SETTINGS.md）同時生效

## 🎮 操作方式
- **移動**：方向鍵 / WASD / 螢幕上的方向按鈕（支援觸控）
- **戰鬥**：碰到地圖上的怪獸就會進入單字戰鬥（明雷遇敵，可以繞開）
- **答題**：選對答案 / 拼對單字 → 攻擊敵人；答錯 → 被反擊並顯示正解＋發音

## 📱 PWA（加到主畫面 / 離線遊玩）
兩個版本都已是 PWA：
- **manifest**：[manifest.json](manifest.json)（2D）與 [3d/manifest.json](3d/manifest.json)（3D）— 可分別安裝成兩個 App 圖示（冒險者 / 冒險者+3D 徽章，由 `make_icons.py` 產生）
- **Service Worker**：[sw.js](sw.js) 預快取全部 30 個檔案，策略為「網路優先、離線用快取」— 斷網也能完整遊玩
- **注意**：安裝與離線功能需要 **HTTPS 或 localhost**。在電腦上（localhost）可直接安裝；手機經由 `http://192.168.x.x` 存取時瀏覽器不會提供安裝與離線（僅能加普通捷徑），需將遊戲部署到有 HTTPS 的空間（如 GitHub Pages）後才能在手機上完整安裝
